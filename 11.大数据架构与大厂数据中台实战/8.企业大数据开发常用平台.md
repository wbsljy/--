## 1.数据资产平台的功能
数据资产地图基于元数据提供各类数据检索、数据血缘、数据资产目录、元数据采集和管理、元数据详情查看等功能，旨在帮助用户更加方便快捷的找数、用数。数据资产地图的使用场景主要有：

1、统一的元数据管理平台

电商平台中琳琅满目的商品需要商家的管理和上架，企业生产过程中丰富的元数据也离不开数据人员的管理和治理。我们的产品提供一站式的元数据管理功能，涵盖元数据的采集、注册、治理、发布等全流程，确保最终呈现的元数据高质量、可信赖。

2、统一的找数、看数平台

数据地图汇总了企业的各类元数据，并支持以“资产目录”的方式来组织管理数据。用户通过资产目录找数据，就像我们进入图书馆，可以使用书目检索查看一本书是否存在、它的位置以及详细信息。更可以通过这些信息决定是否使用这本书。同样的，企业用户也可以按照不同业务维度，通过“资产目录”快速找到自己想要的数据。找数据、看数据，就来数据资产地图，成为数据用户的一种习惯。

3、数据血缘全链路分析

企业业务之间和实际数据生产链路往往都存在着错综复杂的依赖关系，某环节变更后很难评估下游的影响范围、并追溯上游产生问题的原因。我们的产品支持以可视化DAG图的方式查看全链路血缘，确保用户清晰掌握数据的完整流向，对数据异常环节及影响范围及时进行干预。



## 2.数据资产平台的架构

| 术语 | 说明 |
|------|------|
| 元数据 | 描述数据的数据，这里指描述表的属性信息。通过元数据来刻画表的技术信息、业务信息、管理信息等，方便数据用户更全面的理解表的含义。 |
| 元数据采集 | 通过技术手段将源数据库中的表结构等信息采集到平台上的过程，叫做元数据采集。采集内容一般包括表名、字段名、字段类型、描述等物理信息，不包含数据内容。 |
| 元数据注册 | 通过手动创建表单、批量导入、系统采集等方式将元数据表信息录入到平台上的过程，叫做元数据注册。元数据注册，是后续做元数据治理的基础。 |
| 元数据扫描 | 通过技术手段连接源数据库并实时查询技术信息，和元数据采集有点类似，差别在于元数据采集后会存储物理信息，元数据扫描只是临时查询不会落库。元数据扫描目前主要应用在元数据治理过程中补充技术信息。 |
| 元数据治理 | 指针对元数据的质量、安全、标准、规范、价值、成本等问题进行的治理和优化。 |
| 元数据确权 | 确权在各行各业都有应用例如基金确权、房屋确权、土地确权等。对于元数据治理领域来说，元数据确权指元数据的资产归属部门，因为资产只有归属到部门后，方便做后续的成本统计、权责问题划分、部门治理效果评估等。 |
| 资产目录 | 指以目录形式分类展示表、指标、标签等资产，方便用户从业务视角等多个维度去寻找数据。类似于图书馆的书目检索如哲学、自然科学、文学、外文等分类。 |
| 数据专辑 | 用户可以自由创建数据专辑，将自己常用的数据表按照业务场景收纳到不同的专辑中，并且专辑可以设置私有或公开，专辑可帮助用户快速收纳常用表，交流分享数据专辑。 |

# 2.数仓数据标准平台(熟悉）

尖叫提示：注意本章节以视频讲解演示为主

数据标准（Data Standard）是指保障数据定义和使用的一致性、准确性和完整性的规范性约束。通俗来讲，数据标准就是对数据(字段)的命名、数据类型、长度、业务含义、计算口径、归属部门等，定义一套统一的规范，保证各业务系统对数据的统一理解、对数据定义和使用的一致性。

## 1.如何进行标准管理

### 1数据标准管理内容

数据元：数据元由一个属性集合规定其定义、标识、表示和允许值的一个数据单元，作为数据标准的实际载体。其基本属性包括标识类、定义类、关系类、表示类、管理类五类属性。其中，标识类、定义类、关系类、管理类属性主要为数据元的业务属性；表示类主要为数据元的技术属性，如数据类型、数据格式、值域等，值域可以引用数据字典。
数据字典：包括字典信息以及字典的码值范围，一般作为数据元的值域。
词根：维护词根中文、英文、简写之间的对应关系。
数据项分类：数据项目录和方案管理。
资源目录配置：用于平台内各类资产分类的资源目录管理。
### 2.数据标准管理流程

标准审核：用于标准生命周期流转审核，对需要进行状态流转的标准提交发布申请后，由标准审核人进行审核，审核通过后状态跳转。
标准发布：展示可发布的列表，可按标准类型规划发布版本，提交发布申请。
发布审核：对于可发布的状态提交发布申请后，由标准审核人进行审核，审核通过后发布生效。

## 2.数据标准平台功能

### 1.标准资产统计

标准资产统计主要对数据元、原始字典、标准字典、词根、数据项分类方案以及资源目录数量的统计，同时还展示数据元和数据字典发布状态情况。


2.标准化统计
标准化统计主要展示当前版本的数据元、标准字典以及资源目录的生效情况，同时还展示了表、字段标准化情况以及数据元、资源目录引用情况。



表、字段标准化情况，通过标准化率来衡量，具体如下：
1. 表标准化率：如果某表已关联数据元的字段数超过了总字段数的60%，则会被纳入标准化表统计；
2. 字段标准化率：如果某字段关联了数据元，则会被纳入标准化字段统计。
3.标准流程统计
标准流程统计主要是对标准审批以及标准发布趋势进行统计，通过标准审批的统计可以了解到标准状态流转以及标准发布申请的审批情况，包括未办结、通过、驳回。标准发布趋势可以了解到标准发布的频率以及数据元和数据字典的总次数。



4.标准执行详情
标准执行详情分为：未引用数据元、标准核标不一致、字段命名不规范。系统默认每天00:00开始执行检测，检测范围为通过模型设计中心创建的表，并在此处更新执行详情。

未引用数据元：系统会检测未引用数据元的字段，且如检测出字段的中/英文名称和数据元的中/英文名称一致时，会推荐该字段关联数据元。



标准核标不一致：系统会针对已引用数据元的字段，检测其中文名称、英文名称、字段类型/长度、码值等是否遵循标准规范，若不遵循则作为核标异常统计到该报告中。字段类型检测暂仅支持以下数据源类型：Hive、MySQL、Oracle、Greenplum、Vertica



字段命名不规范：系统会对模型表进行检测，检测其字段名称是否符合标准的词根翻译命名，对于不符合词根翻译的字段会进行统计。



5.相似性检测
会展示检测出的相似的数据元和词根。系统默认每天00:00开始执行检测，并在此处更新执行详情。相似的判定标准：如果中文或名称的相似度超过50%，则认为是相似。

# 4.数据指标管理平台/系统(熟悉）

尖叫提示：注意本章节以视频讲解演示为主

指标是有业务统计含义的数值，通过度量加工计算可得到指标。度量是来源于业务系统中不经过加工的用于反映和描述事实的数值型数据，不带有细粒度的业务口径。

例如在零售场景，订单表中「支付金额」是一个度量（因为只是描述下单流程的一个事实数据）；基于「支付金额」这个度量，加上各种业务统计口径计算得到「物流运单收入」，这就是一个指标。

在指标平台中，我们将指标分为原子指标、派生指标和计算指标三类：

原子指标：通过数据模型中的度量聚合得到
派生指标：原子指标加上业务口径的筛选得到
计算指标：原始度量或者指标之间通过加减乘除或其他计算公式计算得到

# 5.数据质量与DQC平台(熟悉）

尖叫提示：注意本章节以视频讲解演示为主

数据质量中心围绕完整性、一致性、准确性、唯一性、有效性和及时性等方面监控、衡量数据质量问题、提升企业数据质量。从数据接入、数据加工等环节，评估数据是否能够满足要求，准时产出，便于数据开发了解监控数据异常后是否影响后续的分析任务、是否能快速修复。

数据质量中心通过事前定义数据的监控规则、事中监控和控制数据的生成过程和事后数据评估和问题追溯过程，实现数据质量问题发现的“全面化、自动化、在线化”，从而将业务规范落实到数据开发的每一环节，为企业提供数据治理全生命周期的监管能力。在实际业务场景中，当数据质量出现问题时，如果不能及时的进行报警通知，只能先发现后治理，然后再进行任务返工，会严重影响数据的产出和决策。数据质量中心支持表级、字段级强弱规则的配置，同时系统内置多种监控规则，可以根据配置的监控规则，运行稽核任务，同时，结合数据测试中心、数据资产等产品功能，在资损、财报等场景中普遍适用。

# 6.数据安全管理平台(熟悉）

尖叫提示：注意本章节以视频讲解演示为主

安全中心依托数据等级、用户等级相匹配的数据使用策略，更智能便捷的数据脱敏和数据加密应用能力，帮助用户快速构建基于数据内容的安全能力，满足企业各种场景的数据安全需求，采用系统预制的各种参数，无需过多配置即可直接使用。

具有安全中心所有功能权限的角色：项目组负责人、项目组管理员、项目负责人、项目管理员。



安全中心作为大数据产品体系的安全门户，致力于帮助用户解决所有数据生命周期内的安全问题，提供全方位的安全管控能力，同时在符合安全规范要求下，提供各种风险行为的诊断，核心功能如下：

数据权限申请
安全中心提供各种类型的数据资产的权限申请、权限审批和权限审计功能，实现了最小权限管控，同时和流协打通，方便您查看权限审批的各个环节，及时跟进处理流程，详情参见数据权限申请。

数据权限治理
安全中心提供用户粒度的各种类型资产的权限治理，通过安全分策略，推动用户治理名下的限制权限：库权限、表权限、队列权限、目录权限等。

数据脱敏
安全中心提供数据扫描、数据等级定义、数据脱敏，数据加密等操作，具备支持动态脱敏和静态脱敏的各种脱敏算法，在处理业务数据的过程中，能够快速及时识别存在的敏感数据，保障数据内容的安全可靠。

数据加密
安全中心提供基于规则的数据等级定义，以此为基础的数据加密能力。

权限审计
安全中心能够快速识别存在安全隐患的操作行为，并计入安全分，保障用户行为的安全可靠。

权限中心：权限申请，提供用户对平台库、表资源的申请入口。用户可通过在此处提交申请，获得库、表使用权限。



安全审计中心：安全审计页面访问权限受角色管理功能权限，安全中心-页面-安全审计 问权限管控，可在项目组、项目任一层级授权。数据审计日志展示项目组下各项目数据访问及操作的审计日志，并根据安全等级等筛选。操作审计日志展示当前项目组的操作日志，审计规则对项目组内生效，包括项目外成员对当前项目的操作。审计日志数据支持实时更新。风险事件规则支持定义规则设定风险事件，系统预置譬如查询敏感数据、查询高安全等级数据、下载敏感数据、下载高安全等级数据等规则，同时支持用户自定义事件规则。风险事件记录展示风险规则触发引发的报警记录，可对报警信息进行处理或忽略，也可以查看处理记录。
